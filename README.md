# Bookstore — Django Web Application

![Python](https://img.shields.io/badge/Python-3-3776AB?style=for-the-badge&logo=python&logoColor=white)
![Django](https://img.shields.io/badge/Django-Web-092E20?style=for-the-badge&logo=django)

Online bookstore (librería) built with **Django** — final team project for the Web Programming course at UNSA.

## Features

- Book catalog with categories and detail views
- Cart / order flow managed server-side
- Django admin for inventory management
- Relational data model (books, authors, orders)

## Quick start

```bash
cd libreria_project
pip install django
python manage.py migrate
python manage.py runserver
```
